ИНСТРУКЦИЯ: КАК ИЗМЕНИТЬ САЙТ-ПОДАРОК И ВЫЛОЖИТЬ ЕГО ОНЛАЙН
==========================================================

Все файлы открываются обычным Блокнотом (Windows), TextEdit (Mac, в режиме
«Простой текст») или любым редактором кода (VS Code). Сохраняй в кодировке
UTF-8, иначе русские буквы превратятся в «кракозябры».
Проверить сайт: дважды щёлкни по index.html, он откроется в браузере.


1. ЧТО ГДЕ ЛЕЖИТ
----------------
index.html     главная (заголовок и подпись)
menu.html      меню (названия и подписи карточек)
letter.html    письмо для мамы
final.html     «Вместо заключения...»
moments.html, promises.html, warm.html, wishes.html   страницы разделов
                (сами тексты для них лежат в js/data.js и js/wishes.js)
js/data.js     фото и подписи, обещания, тёплые слова, языки поздравлений
js/wishes.js   365 пожеланий для печенья
css/style.css  цвета и оформление
js/cookie.js   анимация печенья (скорость)
photos/        сюда кладёшь фотографии


2. ГЛАВНАЯ СТРАНИЦА (index.html)
--------------------------------
Найди строки с комментариями «✏️». Меняй текст между тегами:
  <h1>С днём рождения,<br>мамочка</h1>        ← заголовок (<br> = перенос строки)
  <p class="sub">Я приготовил(а) для тебя ...</p>   ← подпись
Языки поздравлений: js/data.js, список greetings.


3. ПИСЬМО (letter.html)
-----------------------
Текст письма лежит внутри <div class="letter"> ... </div>.
Просто замени строки между комментарием «ВПИШИ СВОЙ ТЕКСТ» и подписью.
Новая строка в файле = новая строка в письме. Пустая строка = абзац.
Подпись: <span class="sign">Твой(я) ...</span>
Финальное послание делается так же в файле final.html.


4. ФОТО И ПОДПИСИ (js/data.js, блок photos)
-------------------------------------------
1) Положи фото в папку photos. Названия только латиницей, без пробелов:
   1.jpg, 2.jpg ... 10.jpg
   (лучше уменьшить до ~1200 px по ширине, чтобы сайт открывался быстро).
2) В js/data.js впиши путь и подпись:
   {photo:"photos/1.jpg", text:"Наша первая поездка на море"},
Если photo оставить пустым "", вместо фото будет заглушка.


5. ОБЕЩАНИЯ, ТЁПЛЫЕ СЛОВА (js/data.js)
--------------------------------------
promises:     10 обещаний, замени текст внутри кавычек. Нумерация ставится сама.
compliments:  фразы для кнопки «Согреть меня» (страница «Что-то милое»).
Правила: каждая строка в кавычках "…", в конце запятая (у последней можно без неё).
Если внутри текста нужны кавычки, используй «ёлочки», а не "прямые".


6. ПЕЧЕНЬЕ С ПРЕДСКАЗАНИЕМ (js/wishes.js)
-----------------------------------------
Там 365 пожеланий, по одному в строке в кавычках. Можно менять любые, добавлять
и удалять. Счётчик «№ … из …» подстроится сам. Пожелания не повторяются, пока
не выпадут все.
Скорость анимации: js/cookie.js, числа в строках с T(...) (250, 850, 1050,
1700, 2300 мс). Уменьши числа, и будет быстрее.


7. НАЗВАНИЯ КАРТОЧЕК И ПОРЯДОК (menu.html)
------------------------------------------
Название и подпись карточки лежат в тегах <b>…</b> и <small>…</small>.
Порядок шагов жёстко задан в js/progress.js, строка:
  const STEPS = ['moments', 'promises', 'warm', 'letter', 'final'];
Меняй порядок только вместе с порядком карточек в menu.html.


8. ПОЭТАПНОЕ ОТКРЫТИЕ
---------------------
Сейчас разделы открываются по порядку: фото → обещания → милое → письмо → финал.
Печенье открыто всегда. Чтобы открыть всё сразу (для проверки), в js/data.js:
  unlockAll: true
Для мамы верни false. Чтобы пройти путь заново, открой сайт в приватной вкладке
или очисти данные сайта в настройках браузера.


9. ЦВЕТА И ШРИФТЫ (css/style.css)
---------------------------------
В самом начале файла блок :root. Меняй коды цветов:
  --paper  фон,   --green  тёмно-зелёный,   --gold  золото,   --ink  текст.
Шрифты подключаются с Google Fonts (нужен интернет), запасные шрифты прописаны.


10. КАК ВЫЛОЖИТЬ ОНЛАЙН (GitHub Pages)
--------------------------------------
1) Зарегистрируйся на github.com и создай репозиторий (New repository),
   тип Public, имя например mama-gift.
2) Распакуй архив. Открой репозиторий → Add file → Upload files.
   Перетащи ВНУТРЬ всё содержимое папки (index.html, css, js, photos, файлы .html).
   index.html должен лежать в корне репозитория, а не во вложенной папке.
   Нажми Commit changes.
3) Settings → Pages → Branch: main, папка / (root) → Save.
4) Через 1–2 минуты сайт откроется по адресу:
   https://ТВОЙ-ЛОГИН.github.io/mama-gift/
Отправь эту ссылку маме. Лучше открывать с телефона.
Если репозиторий приватный, Pages может быть недоступен. Делай Public и не клади
туда ничего, что не должен видеть чужой человек.


11. КАК ПРАВИТЬ УЖЕ ВЫЛОЖЕННЫЙ САЙТ
-----------------------------------
В репозитории открой нужный файл → значок карандаша → внеси правку → Commit changes.
Через 1–2 минуты обнови страницу сайта (на телефоне подольше потяни вниз или
открой в приватной вкладке, чтобы не показывался старый вариант из кэша).
Новые фото: Add file → Upload files → в папку photos.


12. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------
Фото не видно        → проверь путь и регистр букв: на GitHub Photo.JPG и photo.jpg
                       это разные файлы. Названия лучше писать строчными: 1.jpg
Страница пустая или  → скорее всего, лишняя или потерянная кавычка/запятая в
текста нет             js/data.js или js/wishes.js. Сравни со строкой выше и ниже.
Кракозябры           → пересохрани файл в UTF-8.
Сайт на GitHub       → подожди пару минут, проверь, что index.html в корне и что
не открывается         в Settings → Pages включена ветка main.
Печенье не реагирует → сайт открыт без папки js (открывай index.html из распакованной
                       папки, а не прямо из архива).
