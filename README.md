# Сайт-подарок для мамы

## Структура
- index.html: главная
- menu.html: меню
- letter.html, moments.html, promises.html, warm.html, wishes.html, final.html: страницы разделов
- css/style.css: цвета и оформление (цвета в самом начале файла)
- js/wishes.js: 365 пожеланий для печенья (можно менять любые строки)
- js/progress.js, js/cookie.js, js/main.js: логика, менять не нужно
- js/data.js: фото, подписи, обещания, комплименты, воспоминания, языки поздравлений
- photos/: сюда кладёшь свои фото (1.jpg ... 10.jpg), потом пишешь "photos/1.jpg" в js/data.js

## Как выложить онлайн через GitHub Pages
1. Создай на github.com новый репозиторий (Public).
2. Нажми "Add file" → "Upload files", перетащи ВНУТРЬ репозитория всё содержимое распакованной папки (index.html должен лежать в корне, не во вложенной папке) и нажми "Commit changes".
3. В репозитории открой Settings → Pages → Branch: main, папка / (root) → Save.
4. Через 1-2 минуты сайт откроется по адресу https://ТВОЙ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

Чтобы проверить локально, достаточно открыть index.html в браузере.

## Поэтапное открытие
Разделы открываются по порядку: фото → обещания → милое → письмо → финал. Печенье с предсказанием открыто всегда. Чтобы всё проверить сразу, поставь `unlockAll: true` в js/data.js (для мамы верни `false`).
